Sistema de Mercado
Sistema simples em Python para gerenciar setores e produtos de um mercado pelo console.

Estrutura do projeto
mercado_system/
├─ Models/
│ ├─ Mercado.py
│ ├─ Setor.py
│ └─ Produto.py
├─ main.py
├─ .gitignore
└─ README.md

Funcionalidades
Criar e listar setores
Deletar setores
Cadastrar produtos dentro de setores
Remover produtos de setores
Listar todos os produtos por setor
Controlar preço e quantidade de cada produto

Como usar
Tenha Python 3.10+ instalado
Clone o projeto: git clone https://github.com/seu-usuario/nome-do-repositorio.git

Entre na pasta: cd mercado_system
Rode o menu: python main.py
